ทฤษฎีบทที่ 1 • Indivisible Goods Allocation

🎁 1. ทฤษฎีการแบ่งสิ่งของเป็นชิ้น (MNW, Leximin & Adjusted Winner)

💡 อธิบายแบบเข้าใจง่ายเห็นภาพ:
เวลาแบ่งของที่เป็นชิ้นๆ (หั่นครึ่งไม่ได้ เช่น จอคอม หูฟัง คีย์บอร์ด) หากจับฉลาก คนที่อยากได้หูฟังอาจจับได้คีย์บอร์ด ส่วนคนที่อยากได้คีย์บอร์ดกลับจับได้หูฟัง! อัลกอริทึม Maximum Nash Welfare (MNW) จะค้นหาการจับคู่ที่ "มอบของแต่ละชิ้นให้คนที่รักและให้คุณค่ากับมันมากที่สุด" โดยบังคับว่าต้องไม่มีใครถูกทอดทิ้งให้ได้คะแนนต่ำเตี้ยเรี่ยดิน
📐 สมการและเกณฑ์ทางคณิตศาสตร์:
• Maximum Nash Welfare: ค้นหาการจัดสรร (A₁, ..., Aₙ) ที่ทำให้ผลคูณความพึงพอใจ ∏ᵢ uᵢ(Aᵢ) สูงที่สุด
• เกณฑ์ EF1 (Envy-Free up to 1 item): สำหรับทุกคู่ i, j จะมีของอย่างมาก 1 ชิ้น g ในกองของ j ที่เมื่อนำออกแล้ว uᵢ(Aᵢ) ≥ uᵢ(Aⱼ \ {g}) เสมอ (ทฤษฎีบทของ Caragiannis et al., 2019)
• Adjusted Winner (สำหรับ 2 คน): ให้ของแก่คนที่ให้แต้มสูงกว่าก่อน แล้วโอนย้ายชิ้นที่มีอัตราส่วนแต้ม u₁(g)/u₂(g) ใกล้เคียง 1 ที่สุด จนกว่า u₁ = u₂ พอดี
ทฤษฎีบทที่ 2 • Divisible Goods & Cake-Cutting

🍰 2. ทฤษฎีการตัดเค้กและแบ่งสัดส่วน % (Envy-Free CEEI Equilibrium)

💡 อธิบายแบบเข้าใจง่ายเห็นภาพ:
สมมติเค้กก้อนหนึ่งมีทั้งหน้าช็อกโกแลตและหน้าสตรอว์เบอร์รี หรือการแบ่ง "เวลาใช้ห้องประชุม / งบประมาณ" ถ้าเราแบ่งครึ่งทุกอย่าง 33.3% เท่ากันเป๊ะ ทั้งที่ทีม A อยากได้งบโฆษณาแต่ไม่อยากได้ห้องเช้า ระบบจะขยับเปอร์เซ็นต์ให้ทีม A ได้งบโฆษณาเยอะขึ้น และให้ทีม C ที่ชอบช่วงเช้าได้เวลาเช้าเยอะขึ้น จนทุกคนได้ความพึงพอใจสูงถึง ~50–60% (มากกว่าการหารสามแบบทื่อๆ ที่ได้แค่ 33.3%!)
📐 สมการ Eisenberg–Gale & CEEI Equilibrium:
• คำนวณสัดส่วน xᵢⱼ ∈ [0, 1] โดยที่ ∑ᵢ xᵢⱼ = 1 สำหรับทุกรายการ j
• หาจุดสูงสุดของ ∑ᵢ ln( ∑ⱼ xᵢⱼ · vᵢⱼ ) ซึ่งให้ผลลัพธ์ที่เป็นทั้ง Strict Envy-Free 100% (uᵢ(Xᵢ) ≥ uᵢ(Xₖ) ทุกคู่) และ Proportional (uᵢ(Xᵢ) ≥ 1/N) เสมอ

🧹 3. การแบ่งเวรทำงาน (Chores) & 🏠 4. การหารค่าเช่าห้อง (Rent Division)

🧹🧽

ทฤษฎีที่ 3: การแบ่งภาระงาน/เวร (EF1 Chores)

เข้าใจง่าย: คะแนนในโหมดนี้คือ "ความเหนื่อย/ความเกลียดงานนั้น" เช่น ต้นเกลียดการล้างห้องน้ำมาก (ให้ 9/10) แต่บีมมองว่าการล้างห้องน้ำไม่ยาก (ให้ 4/10) ระบบจะจัดให้บีมรับหน้าที่ล้างห้องน้ำ แล้วให้ต้นไปทำหน้าที่จ่ายตลาดและถูพื้นที่ต้นมองว่าสบายกว่าแทน!

📐 หลักคณิตศาสตร์ Min-Max Burden:
• ปรับฐานคะแนนความเหนื่อยรวมของแต่ละคนเป็น 100% ก่อน (ป้องกันคนแกล้งให้ทุกงาน 10 เต็ม 10 เพื่ออู้งาน!)
• ค้นหาการจัดเวรที่ทำให้ ค่าความเหนื่อยสูงสุดของคนที่รับหนักสุดมีค่าน้อยที่สุด (Min-Max Disutility) ภายใต้เงื่อนไข EF1 for Chores
🏠🔑

ทฤษฎีที่ 4: หารค่าเช่าห้องแบบไม่อิจฉา (Rent Division)

เข้าใจง่าย: คอนโดค่าเช่ารวม 18,000 บาท มี 3 ห้องขนาดไม่เท่ากัน ถ้าหาร 6,000 เท่ากัน ทุกคนจะแย่งห้องใหญ่สุด! ระบบจึงให้ทุกคนประเมินราคาที่ตัวเองยอมจ่ายในแต่ละห้อง แล้วคำนวณราคาใหม่ เช่น ห้องใหญ่ 7,900฿, ห้องกลาง 5,700฿, ห้องเล็ก 4,400฿ จนทุกคนรู้สึกว่า "ห้องและราคาที่เราได้คุ้มที่สุดแล้ว ไม่อยากสลับไปห้องเพื่อนเลย!"

📐 หลักคณิตศาสตร์ Utilitarian + Equalized Surplus:
• ขั้นที่ 1: หาการจับคู่ห้อง π ที่ทำให้ผลรวมมูลค่าประเมิน ∑ᵢ vᵢ(π(i)) สูงสุด
• ขั้นที่ 2: หาเวกเตอร์ราคา p₁ + ... + pₙ = R ที่ทำให้ส่วนเกินความคุ้มค่า sᵢ = vᵢ(π(i)) - p_π(i) ≥ vᵢ(π(j)) - p_π(j) และเกลี่ยส่วนเกินให้เท่ากันทุกคน
ทฤษฎีบทที่ 5 & 6 • Knaster’s Sealed-Bid & Shapley Value Cost Sharing

🏛️ 5. แบ่งมรดกพร้อมเงินชดเชย & 🚕 6. หารค่าแท็กซี่ด้วย Shapley Value

🏛️💸

ทฤษฎีที่ 5: ประมูลแบ่งมรดก + เงินชดเชย (Knaster’s Bid)

เข้าใจง่าย: เมื่อต้องแบ่งทรัพย์สินชิ้นใหญ่ที่มีมูลค่าต่างกันมาก (เช่น รถยนต์ 1 คัน กับนาฬิกา 1 เรือน ให้พี่น้อง 3 คน) คนที่ให้ราคารถสูงสุดจะได้รถไป แต่ต้อง "ควักเงินสดจ่ายเข้ากองกลาง" เพื่อนำไปแบ่งชดเชยให้น้องที่ไม่ได้รถ จนสุดท้ายทุกคนได้รับมูลค่าสุทธิ (ของ + เงินสด) สูงกว่า 1/3 ของที่ตัวเองประเมินไว้ทุกคน!

📐 สูตรของ Bronisław Knaster (1946):
1. มอบชิ้น j ให้ผู้ที่ประมูลสูงสุด b*ⱼ = maxᵢ bᵢⱼ
2. คำนวณส่วนแบ่งพื้นฐาน Sᵢ = (∑ⱼ bᵢⱼ) / n
3. คำนวณโบนัสกองกลางส่วนเกิน Bonus = (∑ⱼ b*ⱼ - ∑ᵢ Sᵢ) / n
4. ยอดเงินสดสุทธิของคนที่ i = (Sᵢ + Bonus) - (มูลค่าของที่ i ชนะประมูล)
🚕📍

ทฤษฎีที่ 6: หารค่าแท็กซี่ตามระยะร่วม (Shapley Value)

เข้าใจง่าย: ฟ้า (ระยะ 150฿), ภัทร (ระยะ 300฿), และภูมิ (ระยะ 450฿) นั่งแท็กซี่คันเดียวกันจ่ายรวม 450฿
• ช่วงที่ 1 (0–150฿ แรก): นั่งมาด้วยกันทั้ง 3 คน → หาร 3 คนละ 50฿ (ฟ้าลงป้ายนี้ จ่ายแค่ 50฿!)
• ช่วงที่ 2 (150–300฿ ถัดมา): เหลือภัทรกับภูมินั่งต่อ 2 คน (150฿ ÷ 2) → บวกเพิ่มคนละ 75฿ (ภัทรลงป้ายนี้ รวมจ่าย 50+75 = 125฿)
• ช่วงที่ 3 (300–450฿ สุดท้าย): ภูมินั่งต่อคนเดียวอีก 150฿ → ภูมิจ่ายรวม 50+75+150 = 275฿ (รวมสามคน 50+125+275 = 450฿ เป๊ะ!)

📐 สูตร Shapley Value (Airport / Taxi Game):
เรียงลำดับต้นทุนเดี่ยว c₁ ≤ c₂ ≤ ... ≤ cₙ แล้วคำนวณยอดจ่ายของคนที่ i จาก:
Pay(i) = ∑_{k=1..i} [ (cₖ - cₖ₋₁) / (n - k + 1) ]
